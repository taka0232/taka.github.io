# LAN Drop

Windows と iPhone が同じ Wi-Fi にいるときに使える、ローカルファイル共有アプリです。外部サービスやアカウントは不要です。

## 起動

1. Windows に [Node.js](https://nodejs.org/) をインストールします（初回だけ）。
2. `start-lan-drop.bat` をダブルクリックします。
3. 表示された `http://192.168.x.x:8787` のようなアドレスをiPhoneのSafariで開きます。
4. ファイルを選んで送信します。受信データは `received` フォルダに保存されます。

Windows Defender Firewall の許可画面が出たら、**プライベートネットワーク**を許可してください。

## 仕様

- 最大 500MB / ファイル
- PC・iPhoneのどちらからでもアップロード可能
- 保存されたファイルはどちらの端末からもダウンロード可能
- アプリを停止するには、起動中の画面で `Ctrl + C` を押します
